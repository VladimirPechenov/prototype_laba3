# Лабораторная работа №5 - противники, ловушки и здоровье

## Описание выполненной работы

В прототип "Белый обряд" добавлены активные угрозы для survival-horror / stealth уровня на кладбище. Теперь игрок не просто собирает останки и избегает патрулей, а рискует потерять здоровье от врагов и ловушек. Добавлены здоровье, неуязвимость после урона, чекпоинты, аптечки, экран Game Over и кнопки перезапуска/возрождения.

## Типы врагов

| Тип врага | Объект в сцене | Поведение | Угроза для игрока |
|---|---|---|---|
| Базовый патрульный враг | `Cemetery Watchman` | Использует `EnemyAI`: ходит по точкам, при прямой видимости переходит в преследование, рядом атакует | Наносит 20 HP урона с перезарядкой 1.5 с |
| Стелс-патруль | `Gravedigger Patrol` | Использует `EnemyPatrolAI`: патруль, тревога, проверка источника шума/света, погоня, поиск | Реагирует на бег, фонарик и близость игрока, наносит 20 HP |

## Типы ловушек

| Тип ловушки | Объект в сцене | Как предупреждает игрока | Реакция |
|---|---|---|---|
| Колючий куст / шипы | `Trap - Thorn Patch Left`, `Trap - Thorn Patch Right` | Красный мигающий материал на земле | Наносит 25 HP раз в 1 с при нахождении внутри |
| Ритуальная огненная линия | `Trap - Ritual Fire Line` | Красная полоса перед финальной зоной | Наносит 35 HP раз в 1.2 с |
| Ржавые могильные шипы | `Trap - Rusted Grave Spikes` | Красный опасный блок рядом с центральным маршрутом | Наносит 20 HP раз в 0.9 с |
| Проклятая грязь | `Trap - Cursed Mud` | Красная опасная зона у обходного пути | Наносит 15 HP раз в 0.8 с |

## Система здоровья и возрождения

| Параметр | Значение |
|---|---|
| Максимальное здоровье игрока | 100 HP |
| Урон базового врага | 20 HP |
| Урон стелс-патруля | 20 HP |
| Урон ловушек | 15-35 HP в зависимости от типа |
| Время неуязвимости после урона | 1.5 секунды |
| Аптечки | Восстанавливают 30 HP |
| Чекпоинты | `Checkpoint - Entrance Candle`, `Checkpoint - Chapel Candle` |
| Смерть игрока | При 0 HP появляется `GameOverPanel` |
| После смерти | Можно нажать `Restart level` или `Respawn checkpoint` |

## Расстановка угроз на уровне

| Зона | Угрозы | Назначение в балансе |
|---|---|---|
| Вход на кладбище | Нет прямых угроз, первый чекпоинт | Безопасное введение в управление |
| Ряды могил | Аптечка, первая опасная зона рядом с маршрутом | Игрок знакомится с риском без сильного давления |
| Центральный двор | `Cemetery Watchman`, шипы, проклятая грязь | Первое полноценное испытание: враг + обход ловушек |
| Двор часовни | `Gravedigger Patrol`, ритуальная огненная линия, второй чекпоинт, аптечка | Кульминация: совместное использование скрытности, ресурсов и осторожного движения |

## Новые и изменённые скрипты

- `EnemyAI.cs` - базовый конечный автомат врага: `Patrol -> Chase -> Attack`.
- `Trap.cs` - ловушка с trigger-коллайдером, уроном по cooldown и мигающим предупреждением.
- `PlayerHealth.cs` - здоровье игрока, получение урона, invincibility frames, Game Over, Restart и Respawn.
- `Checkpoint.cs` - обновление точки возрождения при входе игрока в триггер.
- `HealthPickup.cs` - аптечка, восстанавливающая здоровье.
- `EnemyPatrolAI.cs` - обновлён: теперь наносит урон через `PlayerHealth`.
- `PlayerController.cs` - обновлён: HUD берёт здоровье из `PlayerHealth`.
- `Lab4SceneBuilder.cs` - обновлён: пересобирает сцену уже с угрозами ЛР5, UI здоровья, Game Over, чекпоинтами и ловушками.

## Вывод

Добавление угроз изменило геймплей с простого исследования кладбища на survival-horror прототип с риском ошибки. Игроку теперь нужно учитывать здоровье, шум, свет фонарика, маршруты патрулей и расположение ловушек. Баланс соответствует концепту "Белый обряд": враги опасны, но не убивают мгновенно; после урона есть 1.5 секунды неуязвимости; аптечки и чекпоинты дают шанс восстановиться, не разрушая напряжение.
